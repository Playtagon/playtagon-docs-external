Launch Debug exposes technical session information that helps developers understand behavior in the test stand.

## MVP Examples

- Current archive version.
- Launch session state.
- Recent errors or validation messages.
- Useful identifiers for support or review.

Debug information should support development without exposing internal infrastructure details in external docs.
