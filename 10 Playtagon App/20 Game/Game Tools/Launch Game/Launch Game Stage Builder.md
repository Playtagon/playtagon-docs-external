Stage Builder helps the team prepare the launch setup used in the test stand.

## MVP Behavior

- Configure launch parameters.
- Test the selected setup in Launch Game.
- Send the current setup to [[Publishing Client Model]] with Publish current setup.

The publishing submission should make clear which setup is being reviewed.
