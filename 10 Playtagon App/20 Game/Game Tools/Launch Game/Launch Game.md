Launch Game lets the team test a built archive before and during publishing.

## MVP Surface

- Game iframe with the game canvas.
- Playtagon controls for balance, currency and scenarios.
- Replay and debug-oriented helpers where available.
- Publish current setup action that transfers launch parameters into [[Publishing Client Model]].

Launch Game is a test stand. Live distribution happens only after [[Publishing]].
