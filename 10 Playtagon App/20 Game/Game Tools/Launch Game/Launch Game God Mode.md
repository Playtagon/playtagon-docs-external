God Mode is a testing mode for controlled outcomes and edge cases when supported by the game and launch runtime.

## MVP Use Cases

- Force specific test scenarios.
- Reproduce edge cases.
- Validate UI and round handling.

God Mode is for testing only and does not define live game behavior.
