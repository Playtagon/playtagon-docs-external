Client Model is the third publishing module.

## MVP Inputs

- Client version.
- Launch setup from [[Launch Game]].
- Language or locale readiness confirmation.
- Visual self-checkers.

Full localization tooling is outside MVP, but the submission still records the client readiness required for review.
