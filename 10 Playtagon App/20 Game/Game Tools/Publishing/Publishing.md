Publishing is the final MVP workflow before a game can go live. It is built around a submission with three modules.

## Submission Modules

| Module | Purpose |
| --- | --- |
| [[Publishing Game Foundation]] | Public title, slug, description and promo asset readiness. |
| [[Publishing Math]] | Archive version, self-checkers and automated checks. |
| [[Publishing Client Model]] | Client version, launch setup, language/locale and visual self-checkers. |

Each module has its own [[Publishing Threads|thread]] for reviewer communication. A game can move toward live only after the submission passes review.
