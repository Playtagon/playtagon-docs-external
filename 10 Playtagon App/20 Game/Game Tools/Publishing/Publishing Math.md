Publishing Math is the second publishing module.

## MVP Inputs

- Selected `.playtagon` archive version from [[Resources Game Archive]].
- Developer self-checkers confirming responsibility for game math.
- Automated checks such as archive integrity, manifest validation, RTP validation, round correctness and randomizer usage.

Standalone math simulation is outside MVP. Required checks run as part of the publishing submission.
