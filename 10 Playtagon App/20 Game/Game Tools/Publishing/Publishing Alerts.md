Publishing Alerts notify the team about important publishing events.

## MVP Examples

- Submission moved to review.
- Review passed or failed.
- 48-hour period started.
- Deployment started.
- Game is live.
- Action is required because a module is incomplete.

Alert delivery mechanics are not part of this external MVP folder.
