Promo Asset Placements explains how approved assets are consumed.

## MVP Placements

- Game cards in the studio dashboard.
- Game Hub cover artwork.
- Public or operator-facing metadata where supported.
- Runtime references through approved external URLs.

The first approved asset for a required type can become the default unless the team chooses another default.
