Resources AI is the Wizard assistance available around Resources.

## MVP Help

- Explain archive validation feedback.
- Suggest next steps after a failed build.
- Point developers to SDK documentation.
- Remind the team which archive version is connected to publishing.

It should not replace archive validation or present future tools as available.
