File Explorer shows the files available inside Resources.

## MVP Scope

- Browse uploaded files.
- Identify archive versions.
- Open build status and validation feedback.
- Keep the team oriented around the latest usable archive.

The page should stay focused on files that support the MVP Play SDK workflow.
