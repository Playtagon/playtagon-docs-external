Game Archive is the central artifact for the MVP workflow. It is a branded `.playtagon` archive, not a generic zip file.

## MVP Behavior

- Each upload creates a version.
- Playtagon validates and builds the archive.
- Successful versions can be launched in [[Launch Game]].
- [[Publishing Math]] references a specific archive version.

A submission should always point to an explicit archive version.
