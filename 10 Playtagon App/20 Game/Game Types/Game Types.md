Game Types define how a new game is created.

## MVP Rule

Only [[Types Play SDK]] is active in MVP. A developer builds the game with the SDK, packages it as a `.playtagon` archive, uploads it in [[Resources]] and completes publishing through [[Publishing]].

Other creator types are future product directions and are intentionally not described in this external MVP folder.
