Play SDK is the active creator type in the MVP.

## Workflow

1. Build the game with the Playtagon SDK.
2. Package the build as a `.playtagon` archive.
3. Upload the archive in [[Resources]].
4. Wait for archive build and validation feedback.
5. Test the game in [[Launch Game]].
6. Complete [[Promo Assets]] and [[Publishing]].

The SDK documentation lives in the dedicated external documentation folder.
