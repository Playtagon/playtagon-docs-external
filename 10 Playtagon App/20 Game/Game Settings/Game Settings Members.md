Game Members controls who can access a specific game.

## MVP Actions

- Add an existing studio member to the game.
- Invite a new collaborator through [[Members Invite]].
- Adjust game and module permissions.
- Review effective access for game tools.

This is the game-side view of [[Members Game Access]].
