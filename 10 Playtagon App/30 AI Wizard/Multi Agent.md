The Multi-Agent Model describes how the Wizard can route work to specialized capabilities while keeping one user-facing assistant.

## MVP Specialization

- SDK help.
- Promo asset guidance.
- Publishing guidance.
- Onboarding support.

Users should experience this as one Wizard, not as separate tools they need to manage.
